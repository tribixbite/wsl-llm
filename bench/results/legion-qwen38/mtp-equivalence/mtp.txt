```python
def merge_sorted_lists(list1, list2):
    merged = []
    i, j = 0, 0
    while i < len(list1) and j < len(list2):
        if list1[i] <= list2[j]:
            merged.append(list1[i])
            i += 1
        else:
            merged.append(list2[j])
            j += 1
    merged.extend(list1[i:])
    merged.extend(list2[j:])
    return merged
```

```bash
find /var/log -type f -exec du -b {} + | sort -rn | head -5
```

**Explanation:**
- `find /var/log -type f` — finds all regular files under `/var/log`.
- `-exec du -b {} +` — runs `du -b` (byte size) on each file, passing as many arguments as possible in one call for efficiency.
- `sort -rn` — sorts numerically in reverse order (largest first).
- `head -5` — takes the top 5 lines.

**Alternative (more precise, shows full path and size in human-readable form):**

```bash
find /var/log -type f -printf '%s %p\n' | sort -rn | head -5
```

This uses `find`'s built-in `-printf` to output the file size in bytes followed by the path, which is faster and avoids spawning `du` for each file.
